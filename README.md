🛍️ Full-Stack E-Commerce Platform
A complete online shop application built with Node.js, Express, and MongoDB. Developed as part of the "NodeJS - The Complete Guide" course on Udemy.

🚀 Features
User registration, login, and authentication (sessions + hashed passwords)

Product catalog with detailed views

Shopping cart and order management

Checkout with Stripe payment integration

Admin dashboard for product and order management

 (MVC pattern)

MongoDB with Mongoose for data modeling

Security: input validation, CSRF protection, error handling

🛠️ Tech Stack
Backend: Node.js, Express.js

Database: MongoDB, Mongoose

Templating: EJS

Authentication: Sessions, bcrypt

Payments: Stripe API


📂 Project Structure

├── app.js
├── controllers/
├── models/
├── routes/
├── views/
├── public/
└── utils/
